# Scenario 4: Select and delete a recorded set

## Setup
Start a new session, add and save an exercise name, then stamp two sets with different Reps or weights.

## Steps
1. Select the first set and verify the weight type, weight, and Reps selectors match it.
2. Select the second set and verify the selectors update to its values.
3. Verify the selected set displays its Delete (×) control.
4. Delete the selected set.

## Expected
Selection restores the set's values; deleting removes only that set, updates the set list, and leaves the other set available to select.

## Run result
PASS on 2026-09-29: switched between 5-rep and 8-rep sets, verified selection restored the Reps value, deleted the selected set, and saved the remaining set.
